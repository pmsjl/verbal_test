# 实验音频

**把音频文件放进本目录即可**，Vite 会在构建/dev 时自动发现并播放。无需改任何配置。

支持的格式（浏览器原生 `<audio>` 能播的都行）：MP3 / M4A / AAC / WAV / OGG / Opus / FLAC。

## 规则

- 本目录只保留 **一个** 音频文件；如有多个，前端按文件名排序取第一个，并在浏览器控制台告警
- 文件名可以是中文、含空格——Vite 会正确编码
- 替换音频：删旧文件、放新文件，保存任意源文件触发 HMR 或重启 `pnpm dev` / 重新 `pnpm build`

## 实验设计要求

- 单一曲目，全体被试听同一份，保证条件可比
- 时长建议 ≥ 5 分钟
- 音量在文件本身控制好，避免实验员现场调音
